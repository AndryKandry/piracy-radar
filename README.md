# Пиратский радар — прототип дашборда антипиратского мониторинга

Кликабельный прототип сервиса регулярного мониторинга поисковой выдачи (Яндекс, Google)
для борьбы с распространением пиратского контента видеосервиса Wink.

Полностью самодостаточный **один HTML-файл** без внешних зависимостей: inline CSS + vanilla JS.
Все данные — демо-генерация в памяти браузера; при перезагрузке страницы состояние сбрасывается.

## Запуск

Любой из способов:

```bash
# 1. Просто открыть файл двойным кликом в браузере
open piracy-radar-prototype.html

# 2. Локальный сервер (python3)
python3 -m http.server 8080
# → http://localhost:8080/piracy-radar-prototype.html
```

Сервер не обязателен — файл работает и с `file://`.

## Что умеет

- **Дашборд мониторинга** — агрегаты по тайтлам: доля пиратской/легальной/информационной
  выдачи, позиция Wink, новые пиратские URL без жалобы, эффект пакетов жалоб.
- **График структуры выдачи** за 7/14/30 дней с флажками дат передачи пакетов юристам
  и линией позиции Wink.
- **Страница тайтла** — динамика, топ-10 выдачи сейчас (появилось/исчезло/сместилось),
  история пакетов.
- **Пакеты жалоб** — выбор пиратских URL → пакет для юристов: список страниц,
  тексты жалоб под адресата (Яндекс / Google / хостер / РКН), копирование, скачивание .txt.
- **Добавление тайтла** по ссылке Кинопоиска, категории, включение/пауза мониторинга.

## DeepSeek (AI-функции)

Кнопка **«✨ AI»** в шапке. Ключ DeepSeek хранится только в localStorage браузера и уходит
напрямую в `api.deepseek.com` (CORS проверен — работает из браузера, прокси не нужен).
Получить ключ: [platform.deepseek.com](https://platform.deepseek.com) → API Keys.

Без ключа всё работает в демо-режиме. С ключом:

| Функция | Где | Что делает |
|---------|-----|------------|
| Классификация выдачи | Тайтл → «Выдача сейчас» | вердикты пират / легально / инфо по доменам снимка; финальное решение остаётся за человеком (вердикт меняется в списке) |
| Черновики жалоб | Пакет → «Готовые тексты жалоб» | полный текст под выбранного получателя; реквизиты, которых нет в данных, помечаются `[УКАЗАТЬ]` |
| AI-разбор | Дашборд / страница тайтла | разбор сводки: узкие места и рекомендации на неделю |
| Проверка связи | ✨ AI | тестовый запрос к API |

Модели: `deepseek-chat` (по умолчанию) / `deepseek-reasoner`.

## Фиксированные параметры мониторинга (по ТЗ)

Регион: Москва · Глубина: топ-10 · Поисковики: Яндекс + Google · Снимок: ежедневно в 09:00.
